# Demo provenance

`badges.png` is an unmodified screenshot of official BB 0.47.1, captured on 7 November 2026 in an isolated disposable runtime. All titles, messages and states are synthetic. No provider credentials or real agent runs were used.

Model & Effort Badges 0.7.1 uses this release’s source, with `placement=tile` (default). Provider colors come from the separate **True Colors** (`provider-brand-marks`) 0.1.3 by **ChrBoebel**, commit [`7a326de2e69b4cff80d2c6fbad9a424dd7dccf73`](https://github.com/ChrBoebel/bb-plugin-provider-brand-marks/tree/7a326de2e69b4cff80d2c6fbad9a424dd7dccf73). Without it, badges are gray.

The six visible rows use high, ultracode, max, medium, high and extra-high effort, in order. The real tooltip reads `Opus 5.5 · Extra High`, using the installed provider catalog. Responsibilities and Subthread Columns were absent. Default dark theme, 1440×900 CSS pixels at 2× scale; PNG 2880×1800. No crop, resize or UI redraw.
