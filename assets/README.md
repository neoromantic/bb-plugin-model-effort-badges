# Demo provenance

The PNG is a screenshot of this plugin version running in an isolated official BB 0.47.1 installation. All thread titles, messages and states are synthetic. No provider credentials or real agent runs were used.

`badges.png` shows model and effort codes on synthetic sidebar rows. Badge placement is tile (the default). Subthread Columns, Responsibilities and True Colors are absent. Without True Colors the codes remain gray and do not identify providers; the full model name is available on hover.
