# Demo provenance

`badges.png` is an unmodified screenshot of official BB 0.47.1, captured on 31 October 2026 in an isolated disposable runtime. All titles, messages and states are synthetic. No provider credentials or real agent runs were used.

Model & Effort Badges 0.7.0 uses public release commit [`ae642c254ade4bf09056042a7f0d267948afdc61`](https://github.com/neoromantic/bb-plugin-model-effort-badges/tree/ae642c254ade4bf09056042a7f0d267948afdc61), with `placement=tile` (default). The provider colors and outline/fill styles require the separate **True Colors** (`provider-brand-marks`) 0.1.3 by **ChrBoebel**, commit [`7a326de2e69b4cff80d2c6fbad9a424dd7dccf73`](https://github.com/ChrBoebel/bb-plugin-provider-brand-marks/tree/7a326de2e69b4cff80d2c6fbad9a424dd7dccf73). Without it, codes are gray and do not identify providers.

Subthread Columns 0.1.0 was installed with columns off; Responsibilities was absent. The real tooltip shows `claude-opus-5-5 · Extra High`: this demo has no provider model catalog, so it uses the raw model ID. Dark theme, 1440×900 CSS pixels at 2× scale; PNG 2880×1800. No crop, resize or UI redraw.
